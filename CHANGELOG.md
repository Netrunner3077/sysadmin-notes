## [0.1.0] - 2026-10-10

### Добавлено

- 12 HTML-страниц:
  - 9 глав курса (введение, ОС, сети, инструменты, безопасность,
    резервное копирование, виртуализация, автоматизация, ресурсы)
  - страница-оглавление курса
  - галерея изображений
  - страница входа / регистрации
- Модульная архитектура CSS — 18 файлов, объединённых через `main.css`
- CSS-переменные (`:root`) для единой цветовой схемы
- Адаптивная вёрстка от 320px до широких мониторов
- Единое меню с выпадающим списком «Ещё ▾»
- Кнопка-бургер с анимацией в крестик на мобильных
- Переключатель «Вход / Регистрация» без JavaScript (через `:target`)
- Живая валидация форм через `:user-invalid` / `:user-valid`
- Навигация «предыдущая / следующая глава» в конце каждой главы
- Кастомный скроллбар для блоков кода
- Плавная прокрутка с уважением к `prefers-reduced-motion`
- Доступность: `aria-label`, `focus-visible`, семантические теги

### Документация

- `README.md` — полное описание проекта, хода выполнения задания,
  соответствия критериям и roadmap
- `CHANGELOG.md` — этот файл
- `.gitignore` — исключения для системы контроля версий
