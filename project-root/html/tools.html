Инструменты, сети и безопасность

Продолжение заметок о системном администрировании Windows & Linux. Здесь — про то, чем сисадмин работает каждый день и как защищает инфраструктуру.

Начать изучение

Инструменты администратора

Независимо от того, работаете вы с Windows или Linux, набор базовых инструментов во многом пересекается. Одни помогают диагностировать сеть, другие — управлять процессами, третьи — следить за состоянием дисков.

Диагностика сети

ping, tracert / traceroute, nslookup, netstat — минимальный набор для проверки связи и поиска проблем.

Мониторинг системы

В Windows — Task Manager и Performance Monitor. В Linux — top, htop, vmstat, iostat.

Работа с файлами

cp, mv, rsync в Linux; robocopy, xcopy в Windows. Автоматизация рутины — половина успеха.

Что важно освоить в первую очередь

  1. Читать логи: journalctl, Event Viewer.
  2. Управлять пользователями и правами.
  3. Планировать задачи: cron, Task Scheduler.
  4. Работать с SSH и удалённым доступом.
  5. Писать простые скрипты на bash и PowerShell.

Сети: база, без которой никуда

Сеть — это кровеносная система инфраструктуры. Даже идеально настроенный сервер бесполезен, если к нему нет доступа. Понимание модели OSI и стека TCP/IP — не «теория ради теории», а рабочий инструмент.

Уровни модели OSI (кратко)

  • 7 Прикладной — HTTP, DNS, SMTP
  • 6 Представления — шифрование, сжатие
  • 5 Сеансовый — установка сессий
  • 4 Транспортный — TCP, UDP
  • 3 Сетевой — IP, ICMP, маршрутизация
  • 2 Канальный — Ethernet, MAC
  • 1 Физический — кабели, сигналы
«Не понимаешь, на каком уровне проблема — начинай снизу. Кабель, потом интерфейс, потом маршрут, потом приложение.»

Безопасность

Безопасность — это не один инструмент, а процесс. Политики, обновления, резервные копии и мониторинг работают только вместе.

Базовые принципы

Принцип Windows Linux
Обновления Windows Update / WSUS apt / dnf / yum
Файрвол Windows Defender Firewall iptables / nftables / ufw
Аутентификация Active Directory, Kerberos LDAP, PAM, SSH-ключи
Логи Event Viewer syslog, journalctl

Правило трёх копий (3-2-1)

  • 3 копии данных
  • 2 разных носителя
  • 1 копия — вне офиса

Практическое задание

Ниже — блок кода с примером скрипта резервного копирования на bash. Стилизуй его так, чтобы он визуально отличался от обычного текста. 

#!/bin/bash
# Простой бэкап каталога /etc
DATE=$(date +%F)
tar -czf /backup/etc-$DATE.tar.gz /etc
echo "Резервная копия создана: /backup/etc-$DATE.tar.gz"
