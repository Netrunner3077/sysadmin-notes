Windows и Linux изнутри

Архитектура, файловые системы, ядро и оболочки двух главных операционных систем. Глава 2 учебного курса.

Архитектура операционных систем

И Windows, и Linux построены по схожей схеме: ядро (kernel) общается с оборудованием, а пользовательские приложения работают через системные вызовы. Различия — в деталях.

Ядро

В Linux — монолитное ядро с модулями. В Windows — гибридное, с подсистемами (Win32, POSIX, WSL).

Драйверы

Linux: модули ядра (.ko). Windows: .sys-файлы, подписанные Microsoft.

Оболочки

Linux: bash, zsh, fish. Windows: cmd, PowerShell, Windows Terminal.

Файловые системы

От файловой системы зависит производительность диска, надёжность и удобство работы с данными. Вот основные варианты.

ФС Платформа Особенности
NTFS Windows Журналирование, права доступа, шифрование
FAT32 Обе Совместимость, но лимит файла 4 ГБ
ext4 Linux Журналирование, стабильность, гибкость
XFS Linux Высокая производительность на больших объёмах
Btrfs / ZFS Linux Снапшоты, контрольные суммы, RAID

Файловая иерархия

Windows использует буквы дисков (C:\), Linux — единое дерево, начинающееся с /. Это одно из ключевых отличий, к которому привыкаешь не сразу.

Структура каталогов в Linux

  • / Корень файловой системы
  • /etc Конфигурационные файлы
  • /home Домашние каталоги пользователей
  • /var Переменные данные (логи, очереди)
  • /usr Пользовательские программы
  • /tmp Временные файлы
  • /opt Дополнительное ПО

Ключевые каталоги Windows

  • C:\ Системный диск
  • C:\Windows Системные файлы ОС
  • C:\Program Files Установленные программы
  • C:\Users Профили пользователей
  • C:\Temp Временные файлы

Пакетные менеджеры

Установка и обновление программ — ежедневная задача администратора. В Linux для этого исторически служат пакетные менеджеры, в Windows аналог появился относительно недавно.

apt / dnf / pacman

Пакетные менеджеры Debian/Ubuntu, Fedora/RHEL и Arch. Установка: sudo apt install nginx.

winget / Chocolatey

Современные менеджеры пакетов для Windows. Работают из командной строки и PowerShell.

Snap / Flatpak

Универсальные форматы для Linux с изоляцией приложений. Удобны для GUI-программ.
